# LedWell

LedWell is a live video mixer for screens, projectors and ledwalls. Play and mix videos, images, cameras, capture devices, app windows, text and countdowns, and add real-time effects in time with the music.

![LedWell](docs/og.jpg)

## Features

- Preview and Program workflow with a one-click CUT
- Overlay layers, blend modes and per-item transform
- 15 beat-synced effects with BPM oscillators and one-key presets
- Carousels, compositions and automatic audio loudness normalization
- Multi-display output with virtual screens and mapping
- Remote control from any browser on your network, plus OSC
- Runs on low-end machines and needs no installation: just unzip and launch

## Download

Free 2-day trial included. Windows 10/11, 64-bit.

Download the latest version from the [Releases page](../../releases/latest) or from [ledwell.it](https://ledwell.it/).

> Windows may show a "Windows protected your PC" warning the first time, because the app is not code-signed yet. Click **More info → Run anyway**. You can check the file with the SHA-256 shown on the download page.
